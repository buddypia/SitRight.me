# SitSmart - AI姿勢判定Webシステム

リアルタイムでユーザーの姿勢を検出・分析し、改善アドバイスを提供するWebアプリケーションです。MediaPipeを使用してブラウザ上で完全にクライアントサイド処理を行い、プライバシーを保護しながら姿勢チェック機能を提供します。

## 🚀 機能

- **リアルタイム姿勢検出**: WebカメラからMediaPipeを使用して骨格を検出
- **姿勢分析**: 首、肩、背中の角度を計算して姿勢を評価
- **リアルタイムフィードバック**: 姿勢スコアと改善アドバイスを表示
- **プライバシー保護**: 映像データは外部サーバーに送信されず、ブラウザ内で完結
- **レスポンシブデザイン**: デスクトップとモバイルデバイスに対応

## 🛠️ 技術スタック

- **フロントエンド**: Next.js 15 + TypeScript
- **UI**: Tailwind CSS
- **状態管理**: Zustand
- **AI処理**: MediaPipe for Web
- **開発ツール**: ESLint, Prettier

## 📋 必要条件

- Node.js 18.x 以上
- npm または pnpm
- Webカメラ対応ブラウザ (Chrome, Firefox, Safari, Edge)

## 🔧 開発環境のセットアップ

1. 依存関係のインストール:
```bash
npm install
```

2. 開発サーバーの起動:
```bash
npm run dev
```

3. ブラウザで `http://localhost:3000` にアクセス

## 📝 利用可能なスクリプト

- `npm run dev` - 開発サーバーを起動
- `npm run build` - 本番用ビルドを作成
- `npm run start` - 本番用サーバーを起動
- `npm run lint` - ESLintでコードをチェック
- `npm run type-check` - TypeScriptの型チェックを実行

## 🚀 デプロイ

### Vercel
1. Vercelアカウントにログイン
2. GitHubリポジトリを接続
3. 自動でビルド・デプロイが実行されます

### Netlify
1. Netlifyアカウントにログイン
2. GitHubリポジトリを接続
3. ビルドコマンド: `npm run build`
4. 公開ディレクトリ: `.next`

## 📱 使用方法

1. Webサイトにアクセス
2. 「カメラを開始」ボタンをクリック
3. カメラへのアクセスを許可
4. 画面に表示される映像で姿勢をチェック
5. リアルタイムで姿勢スコアとアドバイスが表示されます

## 🔒 プライバシー

- カメラの映像データは外部サーバーに送信されません
- すべての画像処理はブラウザ内で完結します
- 個人データの保存や送信は行いません
