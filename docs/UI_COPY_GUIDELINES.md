# UI Copy & Terminology Guidelines (SSOT)

本ドキュメントは、SitRightにおける多言語UI文言（日本語・英語・韓国語）の品質基準および用語集（SSOT）を定めます。
将来の機能追加やAIエージェントによるコード変更時に、非標準的な表現や違和感のある俗語が混入することを防止します。

---

## 1. コア原則 (Core Principles)

1. **業界標準・プラットフォーム標準の優先 (Industry Standard Alignment)**
   - W3C、YouTube、Google Chrome、Apple Safari等の主要プラットフォームで定着している用語・アイコンを最優先します。
   - 独自の造語や俗称（例: 「小窓」「ポップアウト窓」など）は使用せず、標準用語（「ピクチャー イン ピクチャー」「Picture-in-Picture」）を用います。

2. **人間工学・解剖学的な正確性 (Anatomical & Ergonomic Precision)**
   - 姿勢改善や身体部位に関する説明文は、俗語や不気味な比喩（例: 「リアル骨」「両方のお尻」）を避け、適切で信頼感のある表現（例: 「関節音」「左右の坐骨」）を使用します。

3. **前向きで明確な指標表現 (Clear & Positive Metrics)**
   - ユーザーの健康改善指標には、システムの初期化と混同する曖昧な語（例: 「リセット」）を避け、達成内容が直接伝わる表現（例: 「姿勢改善」「Recoveries」）を使用します。

4. **具体的で飾らない文 (Plain & Specific)**
   - 何が起きているか・何をすればいいかを、主語のある普通の文で書きます。ログのような体言止め（例: "Prolonged downward tilt detected."）や、中身のない褒め言葉・誇張（例: 「素晴らしい姿勢を維持できています！」「頸椎と背骨のアライメントが整いました」）は使いません。
   - 同じ状態を言い換えた文を並べません（見出しが「良い姿勢」なら、補足は数値や基準との差など別の情報にする）。
   - 英語は sentence case（`Export data`）に統一し、Title Case（`Export Data`）は使いません。音色などの選択肢名は短い名詞にします（`Snap (deep)`, `Click`）。

5. **品位あるUIアクション (Polite & Professional Tone)**
   - トースト通知やボタンのラベルには、子供っぽい口語や過剰な感嘆符（例: 「直した！」）を避け、直感的かつ落ち着いたアクション表現（例: 「姿勢を直した」）を使用します。

## 2. 標準用語集 (Canonical Glossary)

| 概念 / 機能 | 日本語 (ja) | 英語 (en) | 韓国語 (ko) | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **PiP起動** | ピクチャー イン ピクチャー | Picture-in-Picture | PIP 모드 | YouTube / Chrome標準 |
| **PiP解除** | ピクチャー イン ピクチャーを閉じる | Exit Picture-in-Picture | PIP 모드 종료 | 画面復帰アクション |
| **PiP表示中** | ピクチャー イン ピクチャーで表示中 | Showing in Picture-in-Picture | PIP 모드로 표시 중 | メイン表示エリアの案内 |
| **回復統計** | 姿勢改善 | Recoveries | 자세 복귀 | 通知後に良い姿勢へ戻った回数 |
| **骨格クリック音** | パキッ！(関節音) | Snap (joint) | 뚝! (관절음) | 解剖学・音響的表現 |
| **深めスナップ音**| パキッ！(深め) | Snap (deep) | 뚝! (깊은 울림) | 簡潔な音色名 |
| **クリックスナップ**| パキッ！(クリック) | Click | 딸깍 (클릭음) | 直感的な操作音名 |
| **理想姿勢ラベル** | 理想 | Ideal | 바른 자세 | 3D 基準シルエット・凡例 |
| **スポーティモデル**| 女性（スポーティ） | Woman (sporty) | 여성 (스포티) | アバター選択名 |
| **エレガントモデル**| 女性（エレガンス） | Woman (elegant) | 여성 (정장) | 英語は形容詞に統一・韓国語は自然な服装名 |
| **頭部前方突出** | ストレートネック | Forward head | 일자목 | パターン名（「姿勢」「자세」付加不要） |
| **座面荷重指導** | 左右の坐骨 | both sit bones / hips | 양쪽 엉덩이 | 正確な重心指導 |
| **一時停止理由** | 横を向いているため計測を一時停止しています | Paused while you look away | 옆을 보는 동안에는 측정을 멈춰요 | 丁寧な案内文 |
| **回復トースト** | 良い姿勢に戻りました | Back to good posture | 좋은 자세로 돌아왔어요 | 表記ゆれ解消（「いい」→「良い」） |
| **トースト確認** | 姿勢を直した | Posture corrected | 자세를 고쳤어요 | 落ち着いたUIボタン |

## 3. 禁止表現リスト (Prohibited Anti-patterns)

| 禁止表現 (Anti-pattern) | 理由 | 採用すべき標準表現 |
| :--- | :--- | :--- |
| ❌ `小窓で表示` / `小窓を閉じる` | 非標準・伝わりにくい俗称 | ⭕ **`ピクチャー イン ピクチャー`** |
| ❌ `Pop out` / `작은 창으로 보기` | 英語/韓国語の非標準表現 | ⭕ **`Picture-in-Picture`** / **`PIP 모드`** |
| ❌ `リアル骨` | 奇怪・不気味で製品品質を損なう | ⭕ **`関節音`** |
| ❌ `スポーツ女性` | 直訳調で不自然 | ⭕ **`女性（スポーティ）`** |
| ❌ `Woman (elegance)` / `여성 (엘레강스)` / `남성 (스마트)` | 品詞不揃い・不自然なカタカナ直訳 | ⭕ **`Woman (elegant)`** / **`여성 (정장)`** / **`남성 (세미정장)`** |
| ❌ `直した！` | 口語・子供っぽいトーン | ⭕ **`姿勢を直した`** |
| ❌ `いい姿勢に戻りました` | 「良い姿勢」との表記ゆれ | ⭕ **`良い姿勢に戻りました`** |
| ❌ `ストレートネック姿勢` / `일자목 자세` | 他パターン（スマホ首、猫背）と不揃い | ⭕ **`ストレートネック`** / **`일자목`** |
| ❌ `両方のお尻に均等に` | 俗語的 | ⭕ **`左右の坐骨に均等に`** |
| ❌ `アライメント` / `alignment` / `align` | 専門用語の飾り。何が良いのか伝わらない | ⭕ **`問題なし` / `All clear`**、**`基準の姿勢に近い状態です`** |
| ❌ `素晴らしい` / `Great posture maintained!` | 中身のない褒め言葉 | ⭕ **`ここまで大きな崩れはありません`** |
| ❌ `Actionable` / `Delivers` / `tailored to` / `stay mindful` / `意識をリセット` / `의식을 환기` | 定型的な宣伝文・AI 調 | ⭕ **`Tip`**、**`Suggests … for today’s most common slip`** |
| ❌ `Fixed!` | 感嘆符付きの口語 | ⭕ **`Posture corrected`** |
| ❌ `Horn bloom` / `Titanium` / `organic` / `ホーン` / `혼 여운` / `티타늄` | 装飾的で音が想像できない | ⭕ **`Snap (deep)`** / **`パキッ！(深め)`** / **`뚝! (깊은 울림)`** / **`딸깍 (클릭음)`** |
| ❌ `ワンポイント` / `원포인트` | 定型句 | ⭕ **`姿勢のヒント`** / **`자세 팁`** |
| ❌ `ゴースト` / `ideal ghost` / `고스트` | 3D 描画の内部用語で利用者に伝わらない | ⭕ **`理想の姿勢`** / **`your ideal posture`** / **`바른 자세`** |
| ❌ 韓国語単独の `이상`（理想の直訳） | 「異常（エラー）」「以上」と誤読される | ⭕ **`바른 자세`** |
| ❌ `당신의` / `머리가 앞으로 떨어져` / `몸의 기울어짐` | 機械翻訳調・不気味な直訳（「頭が落ちる」等） | ⭕ **`내 목 자세`** / **`목과 머리가 앞으로 처져`** / **`좌우 기울어짐`** |

## 4. 自動検証メカニズム (Automated Enforcement)

本ガイドラインで定義された禁止表現および標準表現は、単なるドキュメントに留まらず、自動テストによって恒常的に保護されています。

- **テストファイル**: [`tests/unit/i18n.test.ts`](file:///Users/a13973/dev/buddypia/SitRight.me/tests/unit/i18n.test.ts)
- **テストスイート**: `describe('prohibited terminology and tone contract')`
- **検証内容**:
  1. `MESSAGES` の各言語でPiP標準用語が完全一致すること。
  2. 日本語・英語・韓国語の辞書全体に禁止ワードが含まれていないこと。
  3. `npm test` や CI 実行時に自動実行され、違反時は即座にビルドがブロックされること。
